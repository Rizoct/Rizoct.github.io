01

OVERVIEW

Dossier file

RIZOCT is a personal portfolio site styled after Persona 5 — jagged red / black / off-white panels, halftone texture, scanlines, vignette and skewed kinetic typography — paired with an actual Three.js WebGL world that the page scrolls through: a palace corridor of jagged monoliths, rings to fly through, floating shards and halftone dust. The camera rides the scroll; crossing into a new section fires a signature impact punch.

Built with Vite + Three.js. No framework, no CSS framework — just hand-written vanilla JS and CSS. Everything content-related lives in one file.

Theme #01

Persona-inspired design system — blood red #e60012, ink black #0a0a0c, paper #f6f2e8, halftone overlays, jagged section borders.

World #02

Scroll-driven camera through a 300-unit palace corridor with fog, floor grid, 14 rings, 240 shards and 2,600 dust particles.

Soul #03

Custom cursor, WebAudio menu blips, hover tilt, staggered reveals, depth gauge, loader, impact punch — the game feel layer.

02

FEATURES

Capabilities
  • Scroll-driven 3D camera — smooth lerp (0.075) along a scroll progress value clamped to 0 → 1.
  • Section impact punch — switching sections fires a FOV punch (+9°), light burst and ring scale pop.
  • Persona UI — loader, HUD chips, side nav, depth gauge, halftone / scanline / vignette FX.
  • Kinetic type — skewed stacked hero title with animated data-text layers.
  • 3D card tilt via pointermove on [data-tilt] cards.
  • Staggered reveals via IntersectionObserver (threshold: 0.18).
  • WebAudio blips — tiny synth menu sounds on nav hover / click, start unlocked after first interaction.
  • Graceful degradation — flat page fallback when WebGL is unavailable.

Design decision

Motion is treated as information. The scroll position doubles as camera progress AND "palace depth" (#depth-val), and the section that owns the middle of the viewport becomes the active nav target — the same way confidant ranks surface through the story.

GETTING STARTED

Setup

Prerequisites

Node.js 18+ and npm. No other tooling required.

Install & run

terminal

# dev server → http://localhost:5173
npm run dev

# production build → dist/
npm run build

# serve the production build
npm run preview

THE 3D WORLD

Under the hood

The world is a scroll-driven camera through a long palace corridor. As scroll progress (0 → 1) rises, the camera path is computed per frame:

pathAt(t) 
{
  x: Math.sin(t * Math.PI * 3.0) * 2.4,
  y: Math.sin(t * Math.PI * 2.0 + 0.5) * 1.5 + 0.5,
  z: 10 - t * PATH,
}

Corridor #01

78 jagged monoliths (random height / width / depth / rotation) with red edge lines, plus a wireframe floor grid.

Rings #02

14 torus rings to fly through, breathing and rotating as the camera advances.

Shards & dust #03

240 drifting spinning shards (solid + wireframe InstancedMesh) and 2,600 additive halftone dust particles.

Impact punch

Fired from main.js → scene.impact() whenever a new section takes over. The punch drives FOV (58 → 67), lamp intensity and ring/shard scale, then decays over time.

08

BEHAVIOUR

Systems

Boot & loader

  • Loader animates fill + percentage over 1250ms (250ms when prefers-reduced-motion).
  • On complete: fires the first impact, starts reveals, updates section state, removes loader.

Scroll loop (src/main.js → scrollLoop)

  • Computes page scroll progress 0 → 1 and feeds it to the scene.
  • Updates the palace depth gauge only when the rounded value changes.
  • Runs hero parallax elements via inline --py custom property.

Active section detection

The middle of the viewport (innerHeight * 0.42) owns the current section; it drives nav highlighting and the 3D impact.

Accessibility & fallbacks

  • Respects prefers-reduced-motion — no smooth camera, no tilt, no impact punch.
  • Custom cursor + tilt only on (hover: hover) and (pointer: fine).
  • WebAudio context unlocked on first pointer / key interaction.
  • If WebGL is unavailable the canvas hides and the page works flat.
